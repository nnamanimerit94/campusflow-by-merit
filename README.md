# Campusflow

## Project description

campusflow is basically a command-line helpdesk management system that helps campus staffs record, organise, prioritize, assign and track tickets supports requests. It automatically calculates priority using the value from urgency and affected_users. The system also supports status management system, reports and json persistence.

## Technology
- python3
- python library 
- Git and Github

## Projects features
- Create tickets
- List/View tickets
- Assign tickets
- workflow- A resolved ticket must be explicitly reopened before further permissions for modifications
- work Queue - tickets are arranged based on how it has been prioritized 
- Report - Show total tickets and breakdowns by status and priority; handle zero tickets correctly
- Persistence - A missing json file should allow fresh start, but malformed JSON must produce a clear error rather than silently erase existing data +.
